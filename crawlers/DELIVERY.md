# 桌面采集交付与验证

本次源码副本同步桌面采集及信息聚合，未同步其它并行开发模块。

| 项目 | 结果与边界 |
| --- | --- |
| 采集作业 | 工作台与 MCP 支持进度、幂等请求、取消、显式重试和重启恢复；成功前先导入完整快照 |
| 业务来源 | 新增 HMRC/DfT 官方 Atom，各20条三路一致；3个 Adafruit 商品页 HTTP/浏览器双路相符；CBP 403和Scrapy空结果保留 |
| 正文中文 | 固定发布方正文双路核对；原文、记录版本、译文独立哈希；长文完整分段；机器译文待校对 |
| 运行保护 | 5项运行保护测试、真实控制进程强杀恢复、12项已有故障回归；10分钟118轮合成持续运行，20次失败、24次取消、13次恢复；不表示生产可用率 |
| 开源副本 | 仅自写源码、合成测试、通用文档与依赖锁；不含运行状态、正文/译文、商品图片、凭据、浏览器、容器或第三方运行包 |

开发环境实际通过 stdio MCP 抓到632字符的美联储正文，模型翻译仍有1项数字警告，保持待校对。此项证明抓取和翻译流程连通，没有完成事实核实或人工译文验收。

本副本另建 Python 环境并离线同步锁定依赖，67 项合成回归测试通过；浏览器、原生 Harness iframe 和新 stdio MCP 实际调用分别验证。Harness 验证先运行 `commerce/prepare.py`，只生成被忽略的本机连接定义，不将它们打包。原生测试只适用于本次 macOS/已安装宿主版本，不扩大到所有宿主或 Windows。
