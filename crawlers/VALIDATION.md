## 实际对比结果

合成站点提供相同的静态和 JavaScript 延迟加载页面：三页、八条记录，去重后六种商品，每种五个字段。覆盖多语言、HTML 字符、零价格及零库存。通过要求：全部三页被访问、去重正确、30 个字段逐项精确匹配。公开网站测试各抓取一页，要求十条记录同时具有正文和作者。

| 工具或组合 | 合成静态页 | 合成动态页 | 公开静态练习页 | 公开 JS 练习页 |
| --- | --- | --- | --- | --- |
| Scrapy | 30/30 字段 | 无记录，明确失败 | 10/10 条 | 无记录，明确失败 |
| Crawl4AI | 30/30 | 30/30 | 10/10 | 10/10 |
| Crawlee HTTP | 30/30 | 无记录，明确失败 | 10/10 | 无记录，明确失败 |
| Crawlee Browser | 30/30 | 30/30 | 10/10 | 10/10 |
| Scrapling HTTP | 30/30 | 无记录，明确失败 | 10/10 | 无记录，明确失败 |
| Scrapling Browser | 30/30 | 30/30 | 10/10 | 10/10 |
| Scrapy＋Crawl4AI | 30/30 | 30/30 | 10/10 | 10/10 |
| Crawl4AI＋Scrapling | 30/30 | 30/30 | 10/10 | 10/10 |
| Crawlee＋Scrapling | 30/30 | 30/30 | 10/10 | 10/10 |
| Firecrawl 本地服务 | 30/30 | 30/30 | 10/10 | 10/10 |

十条路线均正确识别合成站点返回的 HTTP 503，没有把空结果报告为成功。缺失字段会返回失败；单独检查确认字符串 `0.00` 和 `0` 不会被误判为空值。

最终矩阵共 50 项：44 项满足提取或错误处理要求，6 项揭示纯 HTTP 路线无法渲染 JS 的能力边界，没有剩余阻塞。不能将纯 HTTP 模式的空结果称为动态抓取成功。主结果位于私有 `.local/crawlers/results/final-validation.json`；初始矩阵、Firecrawl 内网/外网分步结果、各次抓取和日志均保留在私有运行目录。最终组合烟测在字段完整性处理更新后再次通过。

## 单轮耗时观察

| 路线 | 合成静态三页（秒） | 合成动态三页（秒） |
| --- | --- | --- |
| Scrapy | 0.422 | 无目标记录 |
| Scrapling HTTP | 0.104 | 无目标记录 |
| Crawl4AI | 3.302 | 3.667 |
| Crawlee Browser | 1.928 | 4.063 |
| Scrapling Browser | 1.024 | 3.689 |
| Scrapy＋Crawl4AI | 0.365 | 4.766 |
| Crawl4AI＋Scrapling | 1.292 | 3.717 |
| Crawlee＋Scrapling | 2.264 | 4.050 |
| Firecrawl 本地服务 | 3.867 | 4.107 |

这是单轮工具执行时间，包含导入、浏览器启动及页面等待；不同路线执行先后不同，浏览器或系统缓存也会影响结果。没有统计重复、并发负载、内存/CPU 控制或显著性检验，不能据此发布性能排名。

本次样本支持的使用方式：静态内容先用 HTTP；需要动态内容时按需启用浏览器；需要 Markdown 时使用 Crawl4AI。Scrapy＋Crawl4AI 的静态页没有启动渲染器，动态页则实际调用渲染器。两种“渲染/队列＋Scrapling 解析”组合也实际跑通，但未证明组合带来稳定的准确率或速度提升。

## Firecrawl 状态与边界

客户端和本地服务已经安装并通过真实调用。服务端配置来源于官方 `v2.11.162`；该标签的源码构建在容器内下载 pnpm 时失败，实际部署采用 `firecrawl-images.json` 中按摘要固定的官方镜像，不能将它们视为该源码标签的同一构建。

API、浏览器服务、PostgreSQL、Redis、RabbitMQ 和内部合成页服务均已启动；API 健康检查与实际抓取分别验证。浏览器服务使用镜像内已构建的 Node 程序直接启动，解决默认入口临时下载 pnpm 的 DNS 问题。页面缓存已禁用。合成测试使用直接网络，公开练习站使用既有本机代理；两组测试都在同一个本地服务上执行，当前服务保留公开网络代理模式。公开静态/动态练习页分别得到十条完整记录，单轮耗时 3.813/4.745 秒。

官方免密云接口在当前网络出口返回 WebsiteNotSupportedError，说明代理出口需要 API key。没有创建账户或使用付费接口；该失败不作为本地服务能力的结论。

以上均为合成页面与 [Quotes to Scrape](https://quotes.toscrape.com/) 练习页面验证。真实电商网站、登录态、反爬变化、验证码、长期运行和工作台调度没有完成验收。使用方式见 `README.md`。
