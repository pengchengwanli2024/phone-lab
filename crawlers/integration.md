# 来源接入与可靠性完善

日期：2026-11-11。此记录描述当前电脑的本地验证，不是公开发布或真实店铺功能验收。

## 已完成

共享信息聚合现在识别六个来源：USGS、GDACS、WTO news，以及新接入的美联储、ECB、EIA。新增三个来源已实际导入 20、15、20 条记录，共 55 条，可通过现有搜索、分页、本机积累、详情与核查任务流程使用，原文链接、发布方和逐条采集凭据随记录保留。WTO 沿用原来的共享读取器，没有重复导入另一份同源记录。

新来源属于本机多路采集快照。界面显示“导入最近快照”，不会把点击导入说成重新抓取；原始采集时间和导入时间分别保存，超过时效的旧快照仍显示陈旧。MCP 来源查询能读取六个来源；新发现的工具定义支持 `fed`、`ecb`、`eia` 和宏观/能源筛选。已缓存旧工具定义的客户端需重新发现工具后使用新增筛选值。

## 数据保留与失败恢复

- 每个来源分别保存最后尝试回执与最后成功快照，写入通过临时文件和原子替换完成；私有目录/文件分别使用 0700/0600 权限。
- 单独更新一个来源时，四源索引保留其它来源状态。每批原始尝试仍有独立留存目录。
- 失败、单路成功或内容冲突只更新尝试状态，不替换已有成功数据。
- 并发或晚返回的旧采集不能覆盖较新的成功结果；成功快照已落盘但尝试回执未写完时，可以从完整快照恢复状态。
- 导入会检查结构、来源、至少两种工具家族的逐条出处和完整性哈希。损坏、错源、符号链接或缺少出处时拒绝导入，已有后台记录保留。
- 同一来源记录使用稳定 ID，重复导入不重复增加历史；内容版本和已查看状态继续使用既有规则。

完整性检查不证明来源陈述真实，本地结果仍标为发布方陈述，收藏、已查看和多路一致都不替代独立事实核查。

## 使用方式

```sh
# 查看四个电脑端来源的各自尝试与缓存状态，不触发网络请求
.local/crawlers/venv/bin/python crawlers/sources.py --status

# 重新采集一个来源；成功时自动发布本机快照，失败保留旧快照
.local/crawlers/venv/bin/python crawlers/sources.py --source federal-reserve-press
```

然后在工作台“信息聚合”的来源面板点击“导入最近快照”，或调用现有 MCP：

```json
{"name":"commerce_intel_refresh","arguments":{"source":"fed"}}
```

```json
{"name":"commerce_intel_search","arguments":{"source":"fed","category":"macro","limit":"20"}}
```

界面的主题、筛选和基础组件继续复用统一构建产物。新来源没有地理坐标时只进入时间线，不推断坐标、销售国家或店铺影响。

## 当前边界

通用商品/网页抓取仍是 CLI 能力，尚未增加任意网址采集按钮。新增三源的重新联网采集也仍由 CLI 触发；共享界面和既有调度只导入已产生的本机快照。真实店铺登录、验证码、全站覆盖率和全天候运行没有在本次验证中验收。

## 可执行采集任务

工作台“信息源”提供“采集并更新”，与“导入最近快照”分别展示。共享 MCP 新增 `commerce_crawler_start/list/get/cancel/retry`。启动使用 `source`（注册源 ID 或 `all`）和 `idempotency_key`，查询/取消/重试使用 `job_id`。服务端串行执行，保留逐来源进度；已核对的完整来源快照先持久化并导入，再报告任务成功。取消只停止剩余工作；重启将执行中的任务标为中断，需要显式重试。不得将入队回执视作抓取完成。

队列存储和子进程日志在私有运行目录；固定 worker 不接受任意命令。浏览器与 Harness 使用同一生成的界面，旧 MCP 客户端需要重新发现工具表才能显示新增工具。

## 所选文章与中文

`commerce_intel_article_start` 接收所选 `item_id`、`record_sha256` 和幂等键，使用固定发布方主机/路径适配抓取正文；`article_get/list` 读取本机版本；`article_translate` 明确请求中文。后台单次最多 30,000 字符，HTTP 有 2 MB 限制与超时；超限拒绝，不静默截断。标准 HTTP 与系统 curl 的正文须一致。正文只含选定发布方内容区，不含附件或外链全文；USGS/GDACS 等未适配来源明确返回不支持。

HTTPS 主机白名单、重定向检查和 TLS 校验持续启用。直连检查公网 DNS；使用已配置的回环 HTTP 代理时由代理解析远端域名，不虚构本地 DNS 结果。系统 curl 不跟随重定向。

翻译复用现有 Hermes 路由且关闭工具调用；长文切为不超过 5,500 字符的片段，逐批绑定输入哈希，再将中文与完整原文哈希及模型回执绑定。原文、来源记录版本和译文分别留存；机器译文永远为 `pending_review`。数字或币种差异会显示警告，不能将抓取成功当作事实核实或翻译验收。服务重启后不自动重发中断翻译。真实正文和译文只保留在私有状态中。

验收：7 项合成正文/版本/长文/安全回归；真实 stdio MCP 抓到一篇美联储正文（632 字符），双路相符，生成 344 字符中文并保留 1 项数字核对警告。此回执证明流程连通，不证明中文已人工校对。

## 运行保护与本地失败提示

固定源采集在实际启动后至少间隔 90 秒，重复请求排队等待；跨 CLI/作业的公共主机请求间隔 2 秒，遇到已识别的 429/503 使用持久化指数退避（10～300 秒）。该策略覆盖本目录的新采集路径；既有旧源定时刷新仍有自身间隔控制。

单个 route 子进程：CPU 120 秒、单文件 8 MiB、文件描述符 1024；进程组 RSS 每秒检查，超过 1 GiB 时终止本任务拥有的进程组。页面/记录/响应大小和总体时间另有上限；采集作业最长 600 秒。作业证据目录在新作业启动前检查 200 MB 保护阈值，达到时拒绝启动；此项是启动水位，不是整个用户磁盘的硬配额。macOS 本机验证；Windows 的 resource/ps 行为未验收。

失败和中断生成 SQLite 本地告警，工作台“信息源”可确认已查看；确认不删除失败证据、不自动重试，也不向外部渠道发消息。强制终止控制进程的合成测试中，真实 route 被 ownership fence 停止，旧 worker 没有发布快照，任务保留中断并生成告警。10 分钟合成持续运行独立记录实际周期数与资源；不能据此宣称 24 小时或生产可用率。
