# 调研、采集、翻译与证据规范

本项目的调研与平台采集结果统一保留原文、中文翻译、对应证据与明确的不确定性。目标是减少虚假信息、遗漏和重大语义偏差；不能把完整性检查当成真实性证明。

## 工作台使用

1. **运营测算 → 成本测算 / 补货计划**：填写实际参数，点击测算。未知项留空，确认没有该费用时填 0；费用比例按百分数填写。演示样例仅用于试用。结果的“导出测算依据”包含输入、输入哈希、计算口径版本、时间和结果哈希。
2. **连接与知识**：输入中文或英文关键词，搜索已配置的业务目录；打开原文查看内容及 SHA-256。中英检索是词汇匹配，不是自动翻译或事实核查。
3. **调研与采集**：选择通用调研或五个平台模板；记录地区、原文语言、来源 URL、实际采集时间、支持结论的原文，以及截图/文件/批次索引。
4. 每个字段保留原文、中文、原文位置、字段来源和内容性质。没有采集到的信息必须说明限制；不得编造属性、销量、费率或补齐不存在的规格。
5. 点击“自动翻译待译字段”，只发送有原文且中文为空的字段。原文不变，模型结果为待校对；编辑原文或中文会撤销校对状态。修改译文保留模型最初输出与哈希，避免把手动改动归给模型。
6. “检查完整性与译文”列出缺项、缺证、未校对、冲突及数字/币种/单位差异。通过后才能“导出经审阅资料”；结果仍不是已核实的事实或可直接上架的商品。
7. 导出下载 **CSV＋JSON**：CSV 含“原文 / 中文翻译”两栏及来源；JSON 保留原文摘录、翻译来源、检查结果、模板版本与哈希。CSV 引用对应 JSON 的 SHA-256，两份一起保留。刷新面板前先导出；可从 JSON 恢复草稿。

## 证据口径

| 内容 | 必须保留 | 当前校验边界 |
| --- | --- | --- |
| 来源中的陈述 | 链接、采集时间、原文、段落或证据索引、地区/语言 | 调用者提供，尚未独立抓取和核实网页 |
| 模型译文 | 原文哈希、模型/提供方、翻译时间、任务 ID、提示规则版本、最初译文及哈希 | 只代表某模型生成过该译文；待校对 |
| 推算或判断 | 输入、计算模型版本、计算时间、结果、假设 | 输入未独立核实，推算不等于事实 |
| 冲突或未知 | 冲突内容、来源及待核实点 | 阻止正式导出，保留草稿 |
| 截图、PDF、原始采集文件 | 原始文件、路径/批次索引、采集工具与时间 | 当前表单仅记录索引，不自动上传、抓图、核对或归档外部文件 |

哈希用于检查内容是否变化，不能证明内容真实。当前证据包是可下载的本地文件，不是防篡改审计系统。正式业务还需要按来源类型复核时效、独立佐证、样本覆盖和冲突。

## 翻译质量与模型

已按用户选择接入既有 Hermes 模型配置，通过翻译专用子进程调用配置的提供方客户端；不启动通用智能体，不提供工具，不自动切换到其它提供方或未经测试的本地模型。凭据不进入页面、导出或日志。网络复用现有系统代理，仅作用于子进程。

本轮实际路线为 `openai-codex / gpt-6.1-sol`，英文、俄文、日文三个合成样本的数字、币种、单位及否定条件已逐条核对。它不是模型横向评测，不能推断所有语言、长文本或专业法规的准确率。

关键术语、否定句、比较条件、费率、尺寸、币种与日期须对照原文。必要时用另一个已配置且可调用的 Codex / DeepSeek 路线独立复核；记录分歧，不以模型相同意见代替来源验证。本轮未配置新的 DeepSeek 路线，也未完成本地模型对照测试。后续本地测试应使用同一份有标准译文的样本，先通过质量检查再启用。

自动检查保守比较数字及单位标记，可能对正确的本地化写法给出提示，也可能漏掉语义错误；纠正时保留原数值标记便于复核。每批最多 30 项、12,000 字符，超长资料需分批。提交翻译任务后可继续编辑；返回时只填入原文未变且中文仍空的字段。同一提交使用幂等键，网络结果未知时不自动创建另一任务。重启导致中断的任务标记失败，不自动重放。

## 平台采集模板

通用资料覆盖标题、描述、类目、属性、变体/SKU、价格及币种、库存、媒体、尺寸重量、品牌、评论样本、搜索上下文和合规冲突。重点字段不能只采标题和价格就视为完整。

| 平台 | 专项采集重点 | 参考来源与适用边界 |
| --- | --- | --- |
| Ozon | 商品/offer ID、履约模式、条码、Rich Content | [Ozon 内容质量参考](https://docs.ozon.com/retail/actions/rating/)；该 retail 参考不替代跨境店铺规则，未硬编码其分数或阈值 |
| TikTok Shop | 商品/SKU、配送、关联视频/直播样本、资质 | [美国站 Listing Quality](https://seller-us.tiktok.com/university/essay?knowledge_id=481891871868714)；其它站点须另核对 |
| Amazon | ASIN/父子关系、Product Type、Bullet Points、履约、GTIN | [Product Type Definitions API](https://developer-docs.amazon/sp-api/docs/product-type-definitions-api)；实际产品类型定义和站点决定属性要求 |
| Mercado Libre | Item ID、站点、成色、刊登/Catalog、物流 | [类目属性](https://global-selling.mercadolibre.com/devsite/manage-questions-answers-global-selling/atributtes-global-selling)；搜索索引可读，正文直接访问返回 403，须在实际店铺再次核实 |
| Temu | Goods/SKU、经营模式、销售属性组合、产地及合规 | [美国站 Product Attributes](https://partner-us.temu.com/documentation?menu_code=38e79b35d2cb463d85619c1c786dd303&sub_menu_code=c1bf67656f404183997c74675c635087)；站点、类目及条件属性模板另核对 |

参考核对日期：2026-11-10。以上是本项目的采集清单，重点字段是资料完整性要求，**不是五个平台当前全类目的官方必填列表**。每条商品资料还需记录实际站点/类目的规则链接及核对状态；不保证搜索权重、流量、排名或上架。

## 接入约定和验证

未来采集适配器、调研任务、汇总和导出均应沿用该结构；已存在的手机采集脚本尚未改造，历史文件不会自动补证或补译。截图、文件采集与来源真实性核验仍需具体适配器完成。

新增工具：`commerce_collection_template / check / export`、`commerce_translation_start / get`；完整工具表以当前后台发现为准。翻译开始会保存本地任务并调用现有模型，查询和导出内容生成不修改店铺。原始资料及翻译任务保存在私有本机状态，项目发布不包含它们。

验证见 `qa/workbench-ui-result.json`、`qa/workbench-harness-result.json`、`qa/translation-smoke.json` 和 `qa/test_research.py`。界面与数据检查使用合成资料；没有调用真实店铺或执行商品发布。
