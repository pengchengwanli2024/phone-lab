# 候选商品试点接续

「商品试点」读取本机已有试点，明确选择后检查来源清单与实际文件。关联的是已展示的清单版本，沿用原任务 ID、模板和报告，不复制任务，不生成店铺 SKU、商品 ID 或库存关系，也不改写原会话的试点资料。

源报告状态与真实经营门禁分别展示。报告中的 PASS、任务被标为完成、来源完整性通过，都不能使业务验收通过。候选没有实际商品映射时继续保留未知，不挪用其它库存工作项。

现有试点需按清单保存 `pilot-board.json`、`REVIEW.md`，可附已有任务引用及补证模板。读取只检查清单内的本机文件，不访问网页或提交模型。路径限于选定试点目录，拒绝越界、符号链接、过大文件、篡改与清单更新中的不一致。最多100份文件，总量24 MiB；限制失败不会删除证据。

关联不覆盖已有资料。源文件或清单变化时，旧链接保留为历史，需重新核对并按上一链接版本确认。补证下载仅限既有询价清单、成本/补货资料表、素材简报和类目核查清单。下载不会联系供应商、支付样品款、采购或上架；文件均为私有资料，不应随源码发布。

接口：`commerce_pilot_list`、`commerce_pilot_get`、`commerce_pilot_link`、`commerce_pilot_export`。Codex、Hermes 和界面读取同一来源及共享任务状态。源码为 `pilot_bridge.py`，界面规范源为 `web/pilot-ui.js` / `.css`，复用统一组件和内联构建。

候选转真实店铺商品的身份映射尚需明确提供并核对。本入口不自动完成这种映射，也不代替正式报价、实测包装、图片授权、成本资料或岗位产物验收。
