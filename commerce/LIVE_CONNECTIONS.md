# Ozon 俄罗斯与飞书提醒

接入入口为工作台的「Ozon与飞书 → 打开本机接入向导」，也可在项目目录执行 `python3 commerce/open_setup.py`。启动器将短时单次票据交给本机浏览器；票据、Client ID、API Key、Webhook 和签名密钥不进入聊天或 MCP 参数。私有状态不属于公开源码。

## 配置步骤

1. 保留店铺实际的 OGL 名称。Ozon 官方中文帮助将订单入口列为「OGL 和 realFBS」；不能仅凭名称认定 API 覆盖范围。
2. 在卖家后台「设置 → 卖家 API → 生成密钥」选择所需只读角色。支持多选时核对 `Posting FBS read-only` 与 `Product read-only`；若只支持单角色，可核对 `Admin read only`。以当前账号页面和实际接口回执为准。连接器本身仅允许固定读取端点。
3. 在本机向导填写凭据，手动拉取一次，再核对相同时间范围的发货单号、SKU 和数量。首次完整同步只建立基线，不群发历史订单。分页不完整或结构变更时保留之前的有效快照，显示失败原因。
4. 核对原始 `present`、`reserved` 与后台可售数量，明确选择可售口径。库存是履约方式汇总，不能当作单仓。未确认或数据过期时可售数量保持未知，不生成确定采购量。
5. 在指定飞书群创建自定义机器人，填写 Webhook、签名密钥和接收群标签。手动发送一条测试消息，确认目标群收到后再开启推送。接口接收回执不保证手机通知已弹出。
6. 开启自动同步和提醒。默认间隔 120 秒，Mac 休眠、断网或停机期间不保证及时性。可随时在向导暂停。

## 提醒与证据

新发现的待处理发货单去重提醒。库存进入低库存、降为零或恢复后再次下降，按事件周期去重。发送前重新检查最新状态；订单已取消或库存已恢复时不发送旧提醒。发送超时或重启时结果未知的消息不自动重发，避免重复通知。

工作台展示真实提醒、来源时间和快照 SHA-256，支持标为已阅；已阅不代表已经处理。导出来源证据包含规范化业务字段、请求时间范围与分页请求、原始响应哈希、中文字段与状态说明、发送回执和快照哈希。商品名称保留原文，未翻译项明确为待校对。凭据、买家姓名、电话和地址不进入导出或提醒。哈希用于验证留存内容的一致性，不代表外部事实已经独立核实。

本连接不执行发货、改价、改库存、采购、广告或买家消息发送。销售额、价格、汇率与利润不从缺失字段推造；同步发货单数不等同于完整订单账。

## 从真实库存保存补货草稿

「Ozon与飞书」新增接入检查清单、最近通知回执及「真实库存补货计划」。先按产品 ID 和履约方式选择库存记录，再填写同一范围的销量窗口、交期、安全天数、箱规和在途。没有在途须明确填 0；有在途须提供带时区的预计到达时间。销量资料须给出来源和实际核对时间，超过 24 小时需重核；它属于操作者提供的资料，系统没有独立核实。发货单数不会自动换算成销量。

保存草稿会绑定库存快照 SHA-256、原始库存字段、已核对口径和上游请求/响应证据。未核对订单范围、可售口径未知、缺项或资料过期时保留草稿，补货量保持未知。库存快照或口径改变、库存过期、在途预计时间已过时，历史计算留档，当前建议撤回为待核对。可「载入为新草稿」后按最新库存重新测算；不会覆盖原记录或自动下采购单。

草稿可跨客户端查看，导出包含中文字段说明、原始输入、历史测算、当前有效性和完整证据哈希。整箱建议按明确销量窗口外推，只有预计在断货前且规划期内到达的在途才扣减；实际需求和到货仍需人工核对。

新增共享工具：`commerce_live_readiness`、`commerce_live_restock_list`、`commerce_live_restock_save`、`commerce_live_restock_export`。这些工具不接受凭据、不改变自动开关、不向外部发送消息或修改店铺。

## 验证范围

`qa/test_live_planning.py` 验证精确库存映射、幂等、整箱和在途计算、来源变化撤回、资料过期、中文证据及跨账户隔离；隔离浏览器和 Harness 中实际填写、保存和导出草稿。

`qa/test_live_connections.py` 覆盖读取投影、分页、失败保留、初始基线、去重、库存口径、发送状态、回执和证据导出。`qa/live_setup_ui.mjs` 使用隔离 HTTP 服务及合成上游，覆盖私有向导、跨来源拒绝、单次票据、密钥不回显、订单和库存核对、飞书接收确认、启停、真实视图和窄屏键盘操作；不会向真实外部群发送消息。`qa/operations_harness.mjs` 使用已安装 Harness 的隔离运行时验证内联页面及桥接，不代表当前桌面窗口已重载或真实店铺已经验收。

实际账号接入结果只保留在本机私有运行状态。真实读取成功后，仍须由操作者核对订单范围、库存口径及飞书目标群收件；离线夹具不能替代这些步骤。
