# 工作台导航与任务接续

工作台沿用共享蓝白浅色、黑与中性深灰深色及跟随系统。以下功能使用浏览器与 Harness 相同的内联 HTML/CSS/JS，不添加客户端专有业务逻辑、运行时 CDN 或其它框架。

## 从当前工作继续

- 桌面导航按“经营数据、研究与内容、协作执行、连接与能力”分组，只展示当前组的模块。再次进入一个组会回到本面板内最近访问的模块；全部模块仍可通过查找和窄屏选择器进入。
- 使用顶部“查找模块”或 Ctrl/⌘+K，支持中英文关键词、方向键、Enter 与 Escape。已有业务弹窗打开时，快捷键不会替换其未提交内容。
- 首页“接下来做什么”根据当前已读取的来源与共享任务状态提供入口。未配置连接、未确认范围、明确陈旧快照、失败/中断与排队/运行分别处理；缺少新鲜度依据时显示待核对，不将未知当成已过期或已就绪。
- 范围正在加载、发生错误或已经变化时，不显示旧范围的下一步建议。恢复后重新依据当前回执生成入口。建议仅跳转页面，不触发同步、模型分析、采购、平台写入或消息发送。
- 手机首页优先呈现下一步，次要筛选默认折叠。展开筛选后，选定的店铺、市场与平台仍按原有范围逻辑生效。

## 业务页面的工作路径

商品试点、调研来源、成本测算、创意草稿与交付复验提供同一组可展开的路径入口。顺序用于查找工作阶段，不代表自动流水线或门禁已通过。

运营测算和调研页的“关联商品工作项与交付”为选填展开区，继续复用原岗位模块的明确绑定、版本核对及去重交接。未绑定时仍可单独填表；程序不会自动选择商品或把演示输入交付为真实经营资料。

专业页面使用完整内容宽度，取消无关的合成运营助手。相关入口按当前工作给出；总览的侧栏仅显示本机共享任务与本地模板简报，经营图表的模拟范围另有明确标记。

当前服务尚未加载并行新增的评论/客服接口时，显示明确的未启用状态与重试入口；可继续使用商品试点、调研和测算。该状态不通过重启共享后台或开启网关来伪装就绪。

“连接与知识”里的其它平台入口直接进入现有多平台接入页面。配置、授权、范围确认、读取成功与经营验收继续分别核对，连接说明不再声称已有连接器尚未实现。

运营测算、调研、提醒、共享任务和知识等独立页面使用各自的来源说明，不显示无关的全局模拟数据开关。AI 的结构化补充数据仍由原角色模块管理；数字资料可先在运营测算表单补齐，不需要在其它页面复制一套计算逻辑。

## 保留正在进行的工作

同一面板内返回模块时，保留原有业务状态，并恢复已记录的滚动位置与展开区。同页异步更新时，尽量恢复具有稳定 id、name 或 data 属性的输入焦点与文本选择；弹窗外的更新不抢占弹窗焦点。关闭弹窗时返回原触发点并保留滚动位置。

重复点击当前模块不重新读取和重建该模块；需要新数据时使用页面明确的刷新入口。

这些属于当前面板内的交互状态，不是持久化业务保存。刷新、关闭或重开面板后，业务资料以原领域模块的保存、导出和回执为准。没有稳定控件身份或发生范围变更时，不据此保证任意动态控件都能恢复。

## 源码与验证

- `ui/kit.js`：分组导航、完整模块选择器与既有查找组件。
- `ui/next-actions.js`：纯函数、无执行副作用的依据分类与目标白名单。
- `web/workspace-ui.js` / `.css`：下一步、相关入口、路径及视图接续。
- `web/app.js`：保留各领域原实现，仅连接共享导航和状态。
- `ui/build.py`：将源码同步到共享内联产物，不手改生成区块。

组件变动后执行 `python3 commerce/ui/build.py`，并用 `python3 commerce/ui/build.py --check` 核对产物。相关浏览器与原生桥接检查：

```sh
node commerce/qa/workspace_continuity.mjs
node commerce/qa/workspace_continuity_harness.mjs
node commerce/qa/workbench_ui.mjs
node commerce/qa/quality_interactions.mjs
node commerce/qa/launch_ui.mjs
node commerce/qa/organization_exchange_ui.mjs
```

浏览器测试通过 `qa/ui_navigation.mjs` 使用实际可见的分组入口与窄屏选择器，避免直接点击被收起的模块。关联工作项测试使用 `openSection` 明确展开选填区。隔离合成检查不等同于真实店铺、手机、屏幕阅读器、其它宿主版本或正式发布验收；测试截图、日志和本机运行记录保留在私有状态目录。
