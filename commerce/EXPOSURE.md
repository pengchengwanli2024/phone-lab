# 公开信息与经营范围关联

进入「经营关联」，明确选择当前连接已有工作项，再配置销售国家、仓库点位或路线兴趣范围。查询本机已采集的公开元数据，选择一条记录并计算关联线索。没有明确字段或点位时保持资料不足，不从名称、标题或语言猜测位置。

国家字段接受三个英文字母并做完全相等比较；目前校验格式，不验证完整国家代码注册表。国家相同只是广域线索。仓库距离和路线距离使用球面近似；路线采用相邻点之间的最短大圆弧，不表示实际道路或航道。兴趣半径由操作者明确填写，不是灾害影响边界。范围外或字段不同不能证明没有经营影响。

每个工作项最多留存24个范围，其中最多12个启用。每次配置需填写资料来源；编辑按预期版本检查，拒绝覆盖其它会话更新。停用和修改保留旧版本。工作项身份变化后，原配置不再作为当前有效范围，需重新核对并保存。

计算后保存冻结凭据，包含当时的公开来源元数据、配置版本、关联结果与采集状态。超过六小时、时间未知、历史留存或最近采集失败会显示提示；来源自报和采集时间均不证明事件已经独立核实。原来源、范围或采集状态变化后，旧凭据保留并标记变化。实际经营影响始终保持未知，等待复核。

「审阅并创建复核待办」只生成本地共享任务。首次派单重新检查依据版本；重复确认复用同一任务。任务保持 `execution=not_requested`，等待人工或后续明确授权的岗位复核，不由模板执行器冒充完成，也不自动采购、调拨、发送消息或修改店铺。

可明确提交本轮 AI 分析，主题为 `business_exposure`，参数仅允许所展示的 `assessment_id`。模型只能读取这一份关联凭据的精简投影，不取得配置中的原始仓库坐标、路线点位及资料来源备注；公开事件本身的位置仍属于所选来源元数据。模型分析和建议仍待核对，复核建议需按已展示的结果哈希确认，并复用同一个复核任务。不会因为浏览页面或定时采集而调用模型。

证据导出为 JSON，包含完整本地范围、冻结来源和摘要校验值，仅用于私有审阅。校验值用于发现内容变化，不证明来源事实真实；导出不是公开发布附件。

## 共享接口

| 方法 | 参数与作用 |
| --- | --- |
| `commerce_exposure_targets` | `case_id`：读取显式范围及工作项绑定状态 |
| `commerce_exposure_save` | `case_id,data,idempotency_key`：保存范围；编辑另需 `target_id,expected_sha256` |
| `commerce_exposure_assess` | `case_id,item_id`：计算并留存；可带选中记录的 `record_sha256` 防止使用已变化来源 |
| `commerce_exposure_get` | `assessment_id`：读取冻结证据及当前版本检查结果 |
| `commerce_exposure_history` | `case_id`：最近20份冻结凭据 |
| `commerce_exposure_review` | `assessment_id`：经人工审阅后创建一次本地复核任务 |
| `commerce_exposure_export` | `assessment_id`：导出冻结证据，不发送外部通知 |

浏览器、Harness 面板、Codex 与 Hermes 共用后台和记录。界面复用统一组件、主题与三资源内联构建；具体宿主兼容性以[本轮验收](qa/LINK.md)为准。采集器、文章获取、平台适配、岗位契约与网关仍由原模块维护。
