# 稳定经营阶段源码快照

此快照以已冻结的经营工作台为基线，加入研究失败接续、商品证据图片索引、上架身份与资料对照，以及可复用的项目技能。另行进行中的界面重构和研究资料编辑扩展不在本次源码范围内。本机主工作区及正在运行的界面不因准备此快照而回退。

## 包含范围

- 商品按店铺连接与平台商品身份管理，保留原履约范围、来源版本和历史。
- 原图、生成素材与证据来源可追溯；引用证据图片不代表其为已核实商品图或获得发布批准。
- 上架准备显示当前商品、SKU、原店铺、目标店铺，以及采集值、商品工作区当前稿和本店修改；切换目标与加载资料分别确认。
- 对已知的研究规划失败保留原任务、回执和历史，通过明确输入恢复，不重放结果未知的请求。
- 项目经验技能及搜索工具源码位于 `.agents/skills/`，保留来源锁和第三方许可证。AnySearch 是可选的项目 Agent CLI，并未自动接入经营执行器；Open-WebSearch 的 npm 运行时与本机连接配置须自行安装和生成。

## 验证与运行边界

使用 [一键验证](../docs/VERIFYING.md) 核对本快照的明确模块和浏览器门禁。验证器包含本阶段的研究恢复及证据图片专项；未发布功能的测试不构成当前快照的验收范围。任何失败、未运行或源码漂移都不能作为通过。

公开源码不包含真实店铺及客户资料、账号凭据、本机运行配置、业务数据库、商品图片、生成媒体或验收截图。发布专用协作约定与本机内部日志分开维护，已有公开历史另行审阅。

源码发布不代表真实商品已经提交、审核通过或可销售，也不代表手机消息、采购付款、广告、仓库作业或全天无人值守已经验收。独立运行仍依赖本机在线及所需模型、媒体和平台连接配置。
