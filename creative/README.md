# 创意工作室 · 本地基础版

本轮增强与验证见[增强验收记录](../verification/creative-studio-upgrade.md)。

在现有电商工作台选择“创意工作室”。浏览器与 Harness 读取同一份内联界面；新 MCP 会话可发现 `commerce_creative_*`、`commerce_catalog_*` 和 `commerce_media_*` 工具。后台与已有工作台共用服务和账本，创意媒体保存在私有运行状态中。

## 已实现

- 创建项目、按版本保存商品资料、记录来源；三类产物共用同一份产品事实。并发修改会提示刷新，避免覆盖新版本。
- 分片导入 MP4/WebM 参考片、PNG/JPEG 商品图片、WAV 音轨、UTF-8 字幕及外部制作完成的图片/镜头。校验大小、内容格式和 SHA-256；支持相同分片重传及完成回执复用。
- 视频元信息、画面切点候选、最多12张关键帧（无切点时四个时间点）和本机 Vision OCR；优先使用用户提供的口播/字幕。有音轨且校验后的本地 Whisper tiny 缓存可用时，自动提取待校对文本、段落和词时间信息。处理时不下载模型。
- 三套有资料依据的中文模板草稿与30秒分镜。可单独点击 AI 升级，复用既有模型生成目标语言文案，保留引用、模型来源和数字差异提示。模型不带工具，原始视频和图片不随此步骤上传。
- AI 文案先保持待审阅；明确采用后才进入制作。产品资料改变后，旧稿不能直接按旧依据采纳；可在资料未变化时切换同一批候选稿。
- 保留商品原图的三种模板排版 PNG 和可编辑 SVG。模板调整背景、留白与文字，不宣称自动分离了产品主体。
- 将商品图片或已制作镜头与字幕合成30秒图文视频草稿，保留可编辑 ASS 字幕；可选择已导入音轨，也会保留镜头原有音轨。图片作为静态素材、短镜头可能循环，不会自动生成真人或配音。
- 实际执行阶段、完成/部分完成、取消检查点、异常与重启中断回执。模型请求超时或在进行中重启时保留 UNKNOWN，同一幂等键不会自动再次请求。
- 原片分析以时间区间、OCR与关键帧入口呈现；可校对转写并回填参考文案，保留来源素材、哈希和分析任务。回填按版本保存，撤下旧AI采用稿，需重新审阅。
- 项目、文案、分镜、来源、分析与模型回执、素材与哈希导出为JSON，也可下载Markdown制作清单；私有素材可预览和下载。

## 商品浏览与统一创意流程

商品工作区的“商品列表”和创意工作室的“商品与货源”读取同一批已有工作项，以图片卡片和详情展示采集原文、中文资料、原币价格及供应报价。候选不被当作库存，未采到的图片、价格或销量保持缺失。来源图片通过有界公开 HTTPS 读取，保留来源；可明确选择作为产品资料图或设计参考带入关联创意项目。

“产品创意流程”先拆解参考的布局、元素、风格、色彩、字级、卖点表达、镜头和节奏，再记录针对自己产品的调整。可以人工填写，也可明确请求既有 Codex 视觉入口分析参考图片或最多四张视频关键帧；此步骤会上传选定图片，结果先待审阅。参考中的功效或规格不会自动变为自己产品的事实。

同一设计方向组织主图、卖点、细节、场景、产品展示、详情页图片、UGC 视频和展示短视频清单。每个制作版本保留完整提示词、事实引用、参考文件哈希和资料版本。视频清单包含场景、特写、演示与收尾。本机可执行原图排版和五段素材剪辑；新的生成式场景、人物或镜头可提交到明确配置的媒体服务；实际文件校验后进入待审阅。也可继续导入已制作文件。清单建立、外部生成、文件产出和审阅是不同状态，尚未接入生成服务时不会显示已经生图或生视频。成品不可静默覆盖，资料或设计变化后旧版本不能作为当前版本审阅。

可保存按素材版本或商品整体统计的实际曝光、点击、订单、退货和观看数据，保留来源及带时区的统计窗口。空值保持未知，零分母不算成零转化。已有 Ozon 工作项可只读展示同商品、同履约范围的发货单快照；它不等于结算销售额或素材归因。支持 1–90 天本地周期复查及立即复查，原后台周期循环只生成可追溯的调整建议和方案，不自动付费生成或上线。采用复查建议建立新制作版本时，调整原因与数据记录会进入制作清单。进程关闭期间不运行，恢复后合并遗漏周期进行一次复查。

新接口与原创意、报价和商品工作区共用鉴权、私有状态和素材库；不新增店铺发布权限。`commerce/qa/test_product_media.py`、`test_product_media_mcp.py` 与 `product_media_ui.mjs` 提供隔离验收入口；合成测试不替代实际商品、真实生成服务或原生宿主验收。


媒体服务与自建能力复用同一后台：

- 能力库的“我的能力与自动化”可创建、导入、测试、启停和回退技能、HTTP/MCP HTTP 插件、Agent 与声明式工作流。只读测试和模型/外部动作的结构检查分别标记。插件不执行任意代码，MCP 仅支持 HTTP JSON，暂不支持 SSE 与 stdio。
- “模型服务接入”通过本机认证页保存接口与密钥，密钥不经过 MCP。当前提供自定义 JSON、ComfyUI、方舟图片/视频、阿里 Wan 2.1–2.6 首帧视频、MiniMax V2 协议；OpenAI 图片原生接入和 Lovart 直接 API 合同待配置时核对；已连接的宿主插件使用独立账号绑定与方案接续。[旧 OpenAI Videos API](https://developers.openai.com/api/docs/deprecations) 已于 2026-09-24 停服，不能选作可用视频接口。
- 云端账户、部署地址和模型 ID 不预填为已可用。安全连接探测通过也不等于真实生图或生视频成功。每个生成任务冻结制作版本、服务配置和产品图片，回收真实文件后仍须审阅；短镜头可回到原分镜剪辑，不能作为完整视频。
- 手动、间隔、条件和运行后计划保存输入、范围与预算。模型调用需单步批准或本次/计划明确授予的有限预算；对外执行按具体输入批准。排队、已提交、未知、文件回收和审阅独立记录，未知提交不自动重发。模型服务和本地大模型需先实际部署，本项目不隐式下载模型或创建密钥。

## 操作顺序

1. 新建项目，填写商品名称、国家/语言、参考来源；每条卖点用“一条商品事实 | 资料依据”记录。
2. 导入自己的商品图和可使用的参考视频。只有链接时不会自动抓取完整媒体。
3. 在“原片拆解”选择参考视频，查看关键帧、OCR 和口播；机器转写仍需校对。
4. 在原片分析结果中校对口播，点击“已校对，回填参考文案”；闪光或运动也可能触发切点，检测不等于语义分镜。随后在“文案与分镜”查看三种模板，或点击 AI 升级；核对主张与翻译后采用一版。
5. 在“图片与视频”制作三种模板排版，或选择图片/已制作镜头、可选音轨，渲染视频草稿。字幕过长时需要精简文案，系统不会悄悄截掉正文。
6. 预览、下载和导出。真实成片质量、最终观看审阅及效果测试分别记录。

“填入合成示例”只提供明确标注的示例文字，不会把它写成真实商品、客户体验或店铺数据。测试视频采用合成测试图案；它是流程验收材料，不是对外投放成片。

## 当前边界

已接入参考图片与视频采样关键帧的视觉设计拆解。连续镜头的语义动作、配乐节拍、SAM 2 主体分割、直接生成真实场景/演员和跨平台自动投放尚未接入本执行器。当前提供基于画面差异的切点候选、关键帧、模板排版与素材合成，不能等同于完整自动 UGC 重制。

对真实商品，仍可通过 imagegen 或其它已选图像工具制作素材，通过可用视频工具/实拍补充镜头和配音，再作为“已制作图片”“已制作镜头”“补充音轨”导入。实际服务权限、素材可用范围、费用与成品质量按该次制作核对；本实现没有创建新的提供方配置或自动发布内容。

AI 改写的来源引用和数字检查不能证明所有主张真实；“采用”只表示当前调用者已核对，不代表平台认证或独立验证。模板与机器转写都不构成爆款或转化效果保证。

## 环境与运行

基础服务使用现有 Python 运行环境。媒体处理需要 `ffmpeg`、`ffprobe`；模板图片和视频字幕面板需要 `rsvg-convert`。 服务会明确查找固定工具集合，支持私有运行目录中的 `creative-tools.json` 映射；无需依赖终端启动脚本或修改全局 PATH。本机已记录媒体工具的实际位置，路径只保存在私有配置中。Vision OCR 使用项目既有的本机 OCR 程序；缺少时会记录待补充项。当前 FFmpeg 构建没有 libass/drawtext，因此采用 SVG 字幕面板叠加，并另外保留可编辑字幕。

可选语音识别使用现有 `whisper` 命令与 `.local/creative-asr/models/` 下已校验的 tiny 模型和私有 manifest。当前机器已完成官方注册表来源及 SHA-256 校验；其它环境没有该缓存时可先导入字幕，不会隐式下载。模型、媒体、配置和执行日志都不能随源码发布。

AI 文案复用既有 Hermes 运行配置，仅启动固定脚本和直接模型客户端，不启动智能体、不开放工具或跨提供方回退。没有可用配置时任务会保留明确失败回执，本地模板仍可使用。

限制：单文件32MB、视频120秒、图片约1600万像素、每项目100项上传/100次执行，两个并行处理槽；取消在处理检查点生效。当前面向同一位本机用户，不是多租户媒体服务。

```sh
python3 commerce/creative_ui_build.py
python3 commerce/creative_ui_build.py --check
python3 commerce/ui/build.py --check
python3 -m unittest discover -s commerce/qa -p 'test_creative_studio.py' -v
```

`creative_ui.js` 是业务界面源文件；内联模块由构建命令写入 `commerce/web/app.js`，基础 UI 仍由原来的组件与 tokens 管理。

## MCP 入口

`commerce_creative_create/list/get/save` 管理项目；`upload_begin/upload_chunk/upload_finish/asset_read` 管理私有素材；`analyze/review_transcript/refine/approve_script/image_layout/render` 负责处理与审阅；`job_get/job_cancel/export` 管理回执与导出。所有名称加 `commerce_creative_` 前缀。

素材按内容和来源登记，不接受任意本机路径；调用者应保留创建/执行的幂等键，结果未知时先查询原任务。返回的文件内容仍是私有资料，不能直接加入公开发布附件。

完整规划见 [WORKFLOW.md](WORKFLOW.md)，状态与限制以本页及当前验证报告为准。


已连接宿主插件与直接API配置分开：`media-plugin-routing.json` 私有保存选择的账号与一次宿主连接观察，不保存 OAuth。商品制作页可按当前制作版本、产品图片和账号版本准备插件方案，随后创建待确认的执行记录；这两步都不上传、不生成。批准绑定精确方案哈希、原图与账号版本。Lovart 参考图先经其上传工具取得托管URL，再用于生图；HeyGen 使用真实资产ID或受支持的宿主文件，人物、口播和分镜先确认。此路径仍由已连接插件的宿主会话执行，后台不能无人值守调用宿主 OAuth。

`commerce_media_readiness` 和 `commerce_media_overview.readiness` 提供只读制作准备检查，区分制作清单可创建、插件素材输入可用与尚未批准生成。缺项可定位到商品名称、卖点依据、产品原图、参考素材和设计方向；跳转不代替保存，缺少卖点或素材仍可保存资料草稿。检查最近最多8张原图及最多8份参考文件的登记哈希，明确返回未检查数量、文件失效和来源版本变化；不验证画面中的商品身份或参考主张。当前方向引用的文件失效时，制作准备与实际建清单门禁保持一致。原图及用户制作成品不继承参考链接作为来源。连接、内容审阅和一次生成批准仍由具体方案分别核对。

视频方案通过 `commerce_media_plugin_plan_review_video` 审阅人物方式、具体场景、最终台词及原范围内的逐镜头景别与动作；支持虚构成年角色或不出镜、有口播或无口播环境声。当前不接入真人/声音克隆。确认时须对照已有商品依据，内容审阅不会把台词提升为独立核验的产品事实。保存产生新的不可变方案，原方案、原图哈希、商品及账号版本均保留，单镜头仅审阅对应范围。新提示词替换旧台词与机位建议，片段时间从零起算；登录与其它阻塞条件继续有效。内容修改后仍须对新方案单独批准生成，原批准不会转移。

`commerce_media_plugin_execution_start/approve/claim/record_transfer/begin/receipt/get/list/poll_packet/cancel/retry_download` 管理同一执行与共享任务。宿主独占领取凭证、登记真实上传关联后，`begin` 先保存提交意图，再仅返回一次冻结的生成参数。提交中断保留 `unknown`，禁止从插件或其他模型入口重发；有远端ID时只查询原任务。完成回执先进入 `retrieving`，实际文件需有界下载、哈希、媒体探测和完整解码后才登记；结果有效且原商品与账号依据未变时进入审阅。单镜头不会冒充完整视频。取消仅停止本地采用，不声称远端已取消；重试仅回收原结果。回执查询不返回控制凭证、签名下载URL或私有路径。任务入口保留原方案与制作版本；审阅仍需人工核对商品身份和卖点。直接API/ComfyUI沿用原接口，并共享文件验证与未决插件任务门禁。
