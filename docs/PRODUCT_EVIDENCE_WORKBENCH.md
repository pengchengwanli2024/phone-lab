# 商品证据档案与选品评审

入口：主后台 → 店铺管理 → 商品与上架 → 商品工作区 → 选择商品 → **证据与选品**。浏览器与 Harness 复用同一业务域、资料与界面。档案保存于共享 Commerce 主库及私有原图存储，不依赖本地审阅包。

## 查看与维护

- **货源 / 竞品**：保存原始商品链接、来源平台、型号/款式、采集时间、有效期、原文规格、核对状态、冲突、素材权利和原始图片。可登记1688、义乌购、中国制造网、Alibaba、淘宝、京东、拼多多及目标市场平台。来源选择与域名校验相匹配；登记能力不代表已接入各平台登录、批量采集、询价或采购。
- **原图**：PNG/JPEG/WebP 单张最多5MB；上传保留原始字节与SHA-256，或明确点击读取已登记公开图片。每次归档形成来源新版本，历史仍可读；原图与AI生成稿分开展示。图存在、页面能读取或“已本地核对”均不证明实物一致或获得商用授权。
- **原始链接**：点击只请求本机浏览器打开该商品、该来源版本已登记的公开地址，不传平台凭据。打开请求回执不等于网页可达；后台工作区保留，原始href也可复制。
- **报价 / 成本**：直接读取和维护原报价域与原成本表单，不复制另一份价格。报价保留币种、MOQ、交期、包装及有效期，明确选用仍走原同币种报价流程；费用未知保留缺项。
- **理由与约束**：维护客户需求、选择理由、可兑现差异化、风险、进入条件、首测数量、总投入、最大损失和最低贡献率。不知道的金额或数量保留空值。
- **执行记录**：汇总同商品原任务、关联创意处理、证据维护人/时间/版本及评审动作。任务的原状态保持不变；完成技术复查不代表商品可销售。组织任务的organization_case优先，否则精确匹配扩展任务scope.case_id，不按名称或文本模糊关联。
- **历史与恢复**：来源历史可只读查看当时版本及原图；修改保存形成新版本。并发冲突保留输入，核对差异后明确合并到新基线。结果未知时冻结原请求，可核对回执或用同请求安全重试；活动保存期间延后切商品。

## 选品逻辑

采用六项本地判断：目标市场需求、可比竞品与价格、可兑现差异化、完整成本与贡献、实物/报价/履约、资质/标识/素材权利。每项记录判断、理由及当前版本引用；结论为待补证、暂不进入、可有限试销。

“可有限试销”还须通过系统门槛：有已核对且注明时间窗的需求记录；至少两条不同原始链接的可比竞品价格与原图；原工作项明确选用完整有效同币种报价且供应记录完整；完整成本已算出正贡献并与选中报价采购价对应；首测数量符合MOQ/整包装，完整计划成本不超预算，明确止损和贡献率。六项均须给出通过判断及依据。系统门槛是防缺项保护，证据真实性、可比性及经营判断仍需负责人核实。

评审冻结证据指纹。来源、报价、成本、理由或关联创意版本变化后，旧评审显示**依据已变化·需重评**。执行记录新增不会单独使选品依据过期。本地试销结论不授予采购、广告、付款、库存或上架权限，原发布核查保持有效。

## 首个实际案例（2026-11-17）

Ozon/RU/OGL：厨房水槽沥水收纳架（桌面候选），case_id `c2c86d6a2c1a4dd2baf2609933c56bcf`。

主后台已归档3家中国制造网公开供货线索、8张原始参考图、1条Ozon历史竞品线索，关联原3条公开报价、原成本草稿和9项创意素材，保存理由v1与待补证评审。六项原扩展执行按原状态归入该商品。

B2/KIT-45只是补证候选：公开MOQ较低，但Black/Two属性与银色单篮图片冲突；B1为不同按压瓶组合，B3材质声明矛盾。三家均非正式有效报价。竞品只有历史标题线索，无当前价格、销量、评论或原图，不用供应商图/AI图补造。原成本181.53 RUB仅采购参考；九项创意含AI概念图和静态分镜视频，实物身份未确认。

下一次评审先补需求及至少两条有效竞品、确认同款/样品/材质/配件/单件包装与商用权、正式报价及全链路费用；由负责人确定预算、首测量和止损条件后重评。

## 共享接口

`commerce_product_evidence_` 前缀：`get`、`operation_get`、`source_get`、`origin_open`、`source_save`、`proposal_save`、`review_save`、`upload_begin`、`upload_chunk`、`upload_finish`、`image`、`image_capture`。来源和评审写入使用期望版本/证据指纹及幂等键；图片使用商品、来源及准确来源SHA绑定，分片有界且可安全重传。读取原文和公开网页只产生资料，不执行其中的指令。

## 多渠道找货

商品证据页新增“多渠道找货”：公开线索检索、商品元数据或部分原文预览、正常导出资料解析、恢复历史获取结果，再带入原来源编辑保存。15个具名平台与其他供货网站导入入口的实际方式、报价口径与授权边界见[多渠道找货](SOURCING_CHANNELS.md)。
