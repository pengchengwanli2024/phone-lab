# 智能跨境运营平台 · 需求与验收台账

版本：0.2 规划稿；日期：2026-11-12。对应[产品目标](PLATFORM_REQUIREMENTS.md)、[业务与交互](PLATFORM_EXPERIENCE.md)及[扩展规范](PLATFORM_EXTENSIBILITY.md)。当前能力以[证据基线](PROJECT_ALIGNMENT.md)为准；表中“复用”不表示该需求已完整实现。

P0/P1/P2 表示首版先决、高优先后续和后续扩展，不表示已发生线上事故。M0设计、M1一店一商品、M2日常自动准备、M3团队与受控执行、M4扩大覆盖；阶段是门槛，不是日期承诺。新增能力默认处于待设计/实施，涉及真实接入的验收单独记录。

M1 的 B08/流程F04以只读观察、人工处理、明确请求只读回读和复验关闭；未接入平台写入时显示手动交接。B09/流程F06的实时渠道与发送按M3接入，M1只复用本地资料/草稿。M2的自动回读仅在已启用的观察策略内执行，不借此获得平台写入权限。

B09/X04 的渠道目标（Expected）包含飞书、企业微信、微信、钉钉。当前实装（Observed）包括 `live_connections.py` 与 `feishu_sender.py` 的飞书出站通知，以及 `channel_connections.py` 的四渠道接入选择、版本冲突保护与既有 `commerce-bot` 只读诊断。Hermes 已安装飞书、企微、钉钉和个人微信 iLink 适配，但本项目专用 profile 的渠道凭据、运行网关与共享 MCP 配置尚未就绪；保存选择不改变这些配置。公众号/微信客服适配未实装，微信账户类型仍待确定。接口接受、群内实收、手机通知和人员接管分别验收，当前不宣称四渠道完整收发闭环。设置/用户菜单仅表示本机状态与偏好，不代表渠道已授权或团队身份已建立；不修改其它网关以制造接入成功。
