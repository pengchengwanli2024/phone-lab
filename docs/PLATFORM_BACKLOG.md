# 智能跨境运营平台 · 需求与验收台账

版本：0.4 目标对齐稿；日期：2026-11-13。对应[产品目标](PLATFORM_REQUIREMENTS.md)、[业务与交互](PLATFORM_EXPERIENCE.md)及[扩展规范](PLATFORM_EXTENSIBILITY.md)。共42项需求；当前能力以[证据基线](PROJECT_ALIGNMENT.md)为准，表中“复用”不表示该需求已完整实现。三选一、独立项目资产、多设备操作、模型/工作流扩展和移动管理端均为确认目标，未以文档更新关闭验收。

P0/P1/P2 表示首版先决、高优先后续和后续扩展，不表示已发生线上事故。M0设计、M1一店一商品、M2日常自动准备、M3团队与受控执行、M4扩大覆盖；阶段是门槛，不是日期承诺。新增能力默认处于待设计/实施，涉及真实接入的验收单独记录。
