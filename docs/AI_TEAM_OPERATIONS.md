# AI 协作团队的运行方式

本团队用于交付可运行的跨境电商平台。参考 [Lauren Tan 的官方演讲资料](https://ai.engineer/code/2026/talks/lauren-tan)，把重复纠错落实为代码结构、工具约束和可执行验证；不把其他团队的 PR 数量当作本项目的目标或质量保证。

## 职责

| 角色 | 交付 | 写入范围 |
| --- | --- | --- |
| 主控 | 拆解任务、核对依赖、验收和整合 | 已授权的集成与团队登记 |
| 工程交付 | 可重跑验证入口、隔离修复和运行回执 | 当前明确认领的工程文件 |
| 独立审查 | 复现缺陷、风险分级、回归建议 | 独立审查证据，业务代码只读 |
| Ozon 供应链 | 准确 SKU、原始来源、报价与完整成本缺项 | 原商品领域接口，按版本追加 |
| 巡检与记忆 | 运行健康、预算/重复执行、证据时效与待办 | 巡检报告和待核经验 |

实际会话 ID、初始任务、回执和自动化 ID 留在本机私有 `.local/agent-team/`。后台成员档案用于同一项目协作说明；它不证明 Codex 会话在运行，也不自动赋予执行权限。

市场、选品、素材、出单、装箱发货、物流、客服、广告、结算及手机决策的目标、验收与实施顺序见 [经营闭环合同](COMMERCE_AUTOMATION_BLUEPRINT.md)。默认先图文验证商品销量，再评估展示/使用/UGC视频。

## 验证闭环

需求和验收条件 → 明确认领 → 隔离执行 → 一键检查 → 独立审查 → 主控验收 → 保存经验和下轮待办。

验证入口由工程角色首轮交付。缺依赖、失败或无法进行真实 UI 验证时须明确保留状态，不跳过关键检查后宣称通过。验收回执包含被检源码哈希、命令、退出码和覆盖范围；来源变更后重评。截图不能单独证明数据保存或外部动作成功。

重复问题优先沉淀为回归测试、接口或目录依赖约束。经验分为“待核”和“已验收”，保存来源与失效条件，沿用项目现有的工程和业务记忆领域。

项目可复用方法见 [.agents/skills/commerce-evidence-operations](../.agents/skills/commerce-evidence-operations/SKILL.md)：店铺/商品身份、原图与生成图比对、搜索词口径、已知规划失败接续和发布前回读。附带 `readonly-skill.json` 可保存到现有能力注册表，经过只读测试再启用；每次重新绑定 `case_id/platform/store_id/market`，不把旧店铺范围硬编码进公开技能。它复用已有流水线检查，不创建第二个审批器或经营执行器，也不代表无人工经营已实现。

## 调度与权限

新会话先执行明确的首轮任务；日常巡检由应用正式自动化调度，真实计划以应用回执和私有注册表为准。尚未触发的计划不算已完成长期运行验收。

本机已配置每日 03:15 的巡检与 08:30 的经营/工程接续，两者分别保存回执；尚待首次定时触发验收。后台“智能体团队”可查看成员与“工程协作”“Ozon经营”频道；频道是协作配置，实际 Codex 工位见私有注册表，不能把频道讨论视为原任务自动派发成功。

一键入口为 `make verify` 与 `make verify-fast`，覆盖及未覆盖范围见 [VERIFYING.md](VERIFYING.md)。源码变更另运行受影响专项，完整入口不等于全仓全部后端测试、真实店铺或原生客户端验收。

应用会话与后台执行器分别管理。Codex 的巡检自动化依赖宿主；公开资讯采集、Ozon 只读刷新、已启用的声明式计划由共享服务运行。资讯分析可固定使用已测试的本机模型，不读取宿主会话凭据。可选的 `local_model_supervisor.py` 只监督已批准的本机模型进程，健康时复用，不接管或停止其它进程；配置、二进制固定值、启动退避与未知结果均需留存回执。

Mac 保持登录、供电和清醒仍是本机运行前提。一次成功任务不能证明重启恢复或全天连续可用；迁移服务器时须另验恢复、去重、租约、预算与权限。没有配置独立图片提供方时，宿主原生生图不构成后台无人值守生图服务。

商品与素材分别保留原始来源、实际文件及版本。目录按店铺连接和平台商品身份合并库存视图，履约工作项保留；本地素材索引不复制第二份商品事实。生成图先做逐张比对，再由另一角色复核，并列保留初审、纠正与不确定项。看不清的印刷不能写成已核实，疑似差异也不能直接断言商品被改造。视觉候选、实物事实、平台格式、负责人批准分别记录。

工程入口只运行本地验证，不采购、付款、投放广告或上架。对外询价和客户消息需要对应授权。已阻止的站点访问不能通过换工具绕过。既有主目录和真实业务资料保持私有；发布仍执行项目原有清理与验收规则。
