# 多渠道找货

入口：店铺管理 → 商品工作区 → 证据与选品 → 多渠道找货。

## 当前可用流程

1. 选择渠道，输入关键词，检索该渠道的公开线索。摘要只用于发现原始链接。
2. 填写准确商品链接，读取公开页面。能识别的 Product JSON-LD/Open Graph 会保留商品名称、型号、图片链接和原文报价选项；准确商品页只有部分元数据时返回部分预览，不猜测价格。
3. 登录、验证、动态页面或缺少商品结构时，可导入正常取得的单商品 JSON 或含商品元数据的 HTML。导入时仍需提供原始链接。
4. 查看预览后，点击“带入来源编辑，核对后保存”。相同平台和准确链接复用已有来源的新版本，保留原报价绑定和已留存图片；其余形成新来源。
5. 原图留存、报价维护、成本与正式评审继续使用原有领域。来源变更后，原评审按证据版本显示需重评。

平台目录含1688、义乌购、中国制造网、Alibaba国际站、淘宝、天猫、京东、拼多多、义乌小商品城、百度爱采购、慧聪网、世界工厂网、苏宁易购、唯品会、当当，以及其他供货网站的导入入口。

这些是获取资料的适配器，不是已取得各平台 API 授权。界面分别显示公开读取尝试、资料导入、授权接口状态及当前商品的实际回执。当前1688网络读取受限，仅提供资料导入；其他供货网站也仅提供导入。其余渠道的公开读取能否取得数据取决于实际页面，不保证全站覆盖。

## 单商品 JSON 格式

以下为合成格式示例，不是实际报价：

```json
{
  "title": "合成收纳架",
  "supplier": "合成供应方",
  "model": "SYN-01",
  "variant": "银色普通款",
  "description": "导出的商品原文，待核实",
  "images": ["https://images.example.com/product.jpg"],
  "material": "页面声明的材质，未验样",
  "packaging": {"weight_kg": null},
  "offers": [{"price": "12.50", "currency": "CNY", "variant": "银色普通款", "moq": 2}]
}
```

导入上限200KB；不上传 Cookie、密码、令牌或整份账户会话。缺失数据留空。价格区间保留 lowPrice/highPrice，不能把最低价直接作为选定规格的采购价。多商品文档须先选出准确商品。

## 数据和执行边界

- 搜索线索、部分页面预览、结构化预览、失败/需导入分别留存同商品回执，不自动重发。结果未知可刷新回执或以原幂等键查询原请求。
- 回执记录方式、来源链接、取得时间、读取回执或导入内容哈希，并校验完整性；这些不证明卖家陈述真实。
- 公开页面和导入报价均不自动变为正式有效报价。必须核对普通价、会员/券后/拼团价、具体规格、含税运、MOQ、交期、最终包装与有效期。
- 零售参照不默认是可批量采购的货源；同用途不默认是同材质、同结构或同配件。
- 不自动登录、处理验证码、保存平台凭据、采购付款、发送询价或上架。图片只作参考，商业使用需另有授权。

四个共享接口：`commerce_product_evidence_sourcing_channels`、`sourcing_search`、`sourcing_preview`、`sourcing_history`（后三者同前缀）。Codex、Hermes和Harness沿用同一Commerce服务。
